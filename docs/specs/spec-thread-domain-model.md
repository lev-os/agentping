# Thread Domain Model — Behavioral Specification

## Overview

This spec defines the `Thread` type, its associated request/status types, the changes to `Ping`, the new `IThreadStore` port, `ThreadEvents`, and the additions required to `IPingStore` and `AgentPingEvents`.

It is the blocking deliverable for Step 1 of the thread-centric conversion roadmap. No store, service, or HTTP changes may begin until this spec is approved.

---

## Decisions Confirmed

| ID | Decision | Status |
|----|----------|--------|
| D1 | Thread is lightweight metadata; pings carry `threadId` as FK | **confirmed** |
| D2 | New pings require `threadId`; legacy pings default to `NULL`; backfill auto-creates a default thread | **confirmed** |
| D3 | `PingService.submitPing()` auto-creates a thread when `threadId` is omitted | **confirmed** |
| D4 | v1: one agent per thread; `participants[]` deferred to v2 | **confirmed** |
| D5 | `closeThread()` does **not** cascade-dismiss pending pings; pending pings remain and may still be responded to | **confirmed** |
| D6 | `IThreadStore` lives in `packages/core/src/ports/thread-store.ts` (separate file) | **confirmed** |

## `Thread` Type

**File:** `packages/core/src/domain/thread.ts` (NEW)

```ts
import { z } from 'zod';

// ============================================================================
// ThreadStatus
// ============================================================================

export const ThreadStatusSchema = z.enum(['open', 'closed', 'archived']);
export type ThreadStatus = z.infer<typeof ThreadStatusSchema>;

// ============================================================================
// Thread Entity
// ============================================================================

/**
 * Thread — A first-class grouping of Pings from a single agent session.
 *
 * Thread is lightweight metadata. It does NOT embed a pings[] array.
 * Pings reference Thread via Ping.threadId (foreign key pattern).
 *
 * Rationale (D1): Embedding creates hydration complexity and breaks the
 * port/adapter pattern. findByThread(threadId) on IPingStore is the query
 * surface; adapters control join strategy.
 */
export interface Thread {
    id: string;

    // Owning agent
    agentId: string;
    agentName: string;

    // Session linkage — agent-side identifier for the agent run
    sessionId: string;

    // Human-readable summary (optional; derived from first ping if absent)
    title?: string;

    // Lifecycle
    status: ThreadStatus;

    // Freeform bag for adapter/extension use
    metadata?: Record<string, unknown>;

    // Timestamps
    createdAt: Date;
    closedAt?: Date;
}

// ============================================================================
// CreateThreadRequest
// ============================================================================

export const CreateThreadRequestSchema = z.object({
    agentId: z.string().min(1),
    agentName: z.string().min(1),
    sessionId: z.string().min(1),
    title: z.string().optional(),
    metadata: z.record(z.string(), z.unknown()).optional(),
});

export type CreateThreadRequest = z.infer<typeof CreateThreadRequestSchema>;

// ============================================================================
// Thread Filters (for IThreadStore queries)
// ============================================================================

export const ThreadFiltersSchema = z.object({
    status: ThreadStatusSchema.optional(),
    agentId: z.string().optional(),
    sessionId: z.string().optional(),
    limit: z.number().int().positive().optional(),
    offset: z.number().int().nonnegative().optional(),
    createdAfter: z.date().optional(),
    createdBefore: z.date().optional(),
});

export type ThreadFilters = z.infer<typeof ThreadFiltersSchema>;
```

## `Ping` Changes

**File:** `packages/core/src/domain/ping.ts` (MODIFY)

Add `threadId` to the `Ping` interface. Field is optional for backward compatibility with legacy/migrated pings; new pings submitted via `PingService` will always have a `threadId` populated (either explicit or auto-generated by D3).

```diff
 export interface Ping {
     id: string;

     // Who's talking
     agentId: string;
     agentName: string;
     sessionId: string;

+    // Thread grouping — populated by PingService for all new pings;
+    // null on legacy rows that predate thread-centric conversion.
+    threadId: string | null;

     // What they're saying
     type: PingType;
     payload: PingPayload;
```

`CreatePingRequest` also gets an optional `threadId`:

```diff
 export const CreatePingRequestSchema = z.object({
     agentId: z.string(),
     agentName: z.string(),
     sessionId: z.string(),
+    threadId: z.string().optional(), // if omitted, PingService auto-creates a thread (D3)
     payload: PingPayloadSchema,
     expiresInMs: z.number().optional(),
 });
```

## `IThreadStore` Port

**File:** `packages/core/src/ports/thread-store.ts` (NEW)

```ts
import type { Thread, CreateThreadRequest, ThreadFilters } from '../domain/thread.js';

/**
 * IThreadStore — Storage Port for Threads
 *
 * Implemented by storage adapters (SQLite, in-memory, Postgres, etc.).
 * Pings are queried by threadId through IPingStore.findByThread().
 */
export interface IThreadStore {
    // =========================================================================
    // Thread CRUD
    // =========================================================================

    /** Persist a new Thread. Implementations must set createdAt if not present. */
    save(thread: Thread): Promise<void>;

    /** Find a thread by its ID. Returns null if not found. */
    findById(id: string): Promise<Thread | null>;

    /** Find all threads matching the given filters. */
    find(filters?: ThreadFilters): Promise<Thread[]>;

    /** Find all threads for a given agent session. */
    findBySession(sessionId: string): Promise<Thread[]>;

    /** Find all threads for a given agent. */
    findByAgent(agentId: string, filters?: ThreadFilters): Promise<Thread[]>;

    /** Apply partial updates to a thread (e.g. change title, status). */
    update(id: string, updates: Partial<Thread>): Promise<void>;

    /**
     * Mark a thread as closed. Sets status = 'closed' and closedAt = now.
     * Does NOT dismiss pending pings in the thread (D5).
     */
    close(id: string): Promise<void>;

    /** Hard-delete a thread record. Does NOT cascade to pings. */
    delete(id: string): Promise<void>;

    // =========================================================================
    // Lifecycle
    // =========================================================================

    /** Initialize the store (create tables / indexes if needed). */
    initialize(): Promise<void>;

    /** Close the store connection. */
    close_store(): Promise<void>;
}
```
