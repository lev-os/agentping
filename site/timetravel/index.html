The Problem

Agents Are Black Boxes

You can't replay an agent's reasoning. You can't fork its research path. You can't understand why it chose one source over another. The entire deep research space is opaque by design.

?

No Replay

When an agent produces a research report, you get the output. You never see which backends it hit, which sources it discarded, or why it synthesized one thread over another.

!

No Forking

Want to re-run the same query with a different strategy? Start over. Want to swap one search backend for another? Rebuild from scratch. There's no composable research primitive.

&

Vendor Lock-in

Every research agent is a monolith. Perplexity can't use Valyu's proprietary data. Grok can't search arXiv. You're stuck with whatever one company decided to build.

No single backend wins every query. Valyu crushes academic research but can't search Twitter. Grok has real-time X data but can't search PubMed. A router will always outperform a monolith.
The Approach

Router, Not Engine

Lev didn't build another search engine or research agent. It built a research router that treats search backends like interchangeable parts.

timetravel is a plugin with 11 adapters: Brave, Firecrawl, Valyu, Perplexity, Exa, Tavily, Grok, arXiv, HackerNews, ScrapECreators, and an Oracle synthesizer. Each adapter is a thin HTTP client. The router picks a strategy—quick, full, deep, max, social, or academic—fans out to the right backends in parallel, and merges the results.

When a new backend launches that beats Exa on structured extraction, we add one adapter file and it's available to every strategy. When Valyu adds a new data source, every deep research query automatically gets it. The router doesn't care about benchmark wars—it uses the best tool for each job.

// One command. Three paid APIs in parallel. Under 30 seconds. $ timetravel search "deep research agents" -s deep // 185KB of structured JSON. Deduplicated sources. Confidence scores. // Total cost: less than a dollar.
