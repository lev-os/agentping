The Problem

Agent Sprawl Is Killing You

65 coding agents. Each with their own config format, invocation flags, and mental model. You're not building software anymore — you're managing a zoo.

4

Runner Registries

ntm has one. lev harness has another. Poly has a third. ClawTeam built a fourth. None of them talk to each other. Four sources of truth equals zero sources of truth.

3

ExecOptions Interfaces

core/harness has 30+ fields. core/exec has semaphore + eventLogPath. core/domain has timeout + cwd + env. The SDK-first design has profile + prompt + model. None of them match.

Invisible Tiers
