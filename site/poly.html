The Protocol

Two primitives. Infinite composition.

ARM describes capabilities. InvokeEnvelope executes them. That's the entire protocol.

ARM

Agent Runtime Manifest

Describes what an agent can do. Like a Docker image manifest, but for AI agents.

name: lev-agent version: 0.1.0 surfaces: - email # via AgentMail - compute # via Daytona, E2B - browser # via Browserbase - search # via Exa capabilities: - code_execution - web_browsing - communication
InvokeEnvelope

The Runtime Request

The runtime request. Like a container run command, but for agent infrastructure.

target: email action: send params: to: "partner@company.com" subject: "An agent sent this" body: "..." budget: max_tokens: 1000 timeout_ms: 30000
