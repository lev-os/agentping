The Substrate

FlowMind is the CSS for agents.

Declare the topology in YAML. The runtime handles execution, context, and backpressure. Adding a review layer is adding one node.

ralph.flow.yaml simple loop 
# One agent, fresh context, tests as backpressure
name: ralph
entry: work

nodes:
  work:
    type: action
    op: lev.exec
    next: gate

  gate:
    type: action
    op: lev.validate
    branches:
      pass: done
      fail: work

  done:
    terminal: true
work → gate → done
lev-ralph.flow.yaml + review node 
# Sonnet works, Opus reviews AND fixes
name: lev-ralph
entry: work

nodes:
  work:
    type: action
    op: lev.exec
    model: sonnet
    next: gate

  gate:
    type: action
    op: lev.validate
    branches:
      pass: review
      fail: work

  review:
    type: action
    op: lev.exec
    model: opus
    branches:
      green: done
      fixed: gate

  done:
    terminal: true
work → gate → review → done

Adding an Opus code review to your agent loop is one YAML node. Not a new orchestration framework. Not a rewrite. One node.

The Vocabulary

Graph Primitives

Eight first-class concepts define every operation in the system. Everything else is composition.

entity

A node in the graph. Specs, plans, claims, gates.

claim

An atomic assertion with truth state. Proposed, accepted, contested, refuted, superseded.

proposal

A candidate graph mutation. Git analog: pull request. Requires gates to land.

gate

Evaluator that allows, amends, or rejects proposals. Five types: scope, safety, feasibility, standards, progress.

intent

Cascading behavior spec. Governs child entities via links.

loop

Bounded repetition with exit semantics and retry cadence. First-class, not ad hoc.

effect

Observable consequence of execution. File writes, API calls, git commits.

edge

Typed transition between nodes, scopes, or subgraphs.

The Tick Cycle

Every flow reduces to one universal cycle. Seven phases. One substrate.

Ingest → Observe → Propose → Gate → Apply → Update → Emit
